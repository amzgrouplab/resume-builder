    Settings

    Keys stay in this browser and are sent only to the local Vellum server, which calls OpenAI or Anthropic for the rewrite. They are not written to disk on the server.

    Long resumes are rewritten role by role so the full document and the full job description are used. Pick OpenAI or Anthropic in Settings; Vellum uses that provider’s key and model.
